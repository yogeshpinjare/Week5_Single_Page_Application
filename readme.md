
# Week 5 Internship Task
## Developing a Single Page Application (SPA)

### Project Name
Travel Explorer - Single Page Application

### Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Client-Side Routing
- Browser History API
- Responsive Design

### Main Features
1. Single Page Application architecture
2. Dynamic page rendering
3. Client-side navigation
4. URL hash routing
5. Browser back and forward navigation
6. Dynamic destination cards
7. Contact form validation
8. Responsive user interface
9. 404 error page
10. Smooth page transitions

### Project Structure
- index.html
- style.css
- script.js
- README.md

### How to Run
1. Open the project folder in VS Code.
2. Install Live Server if required.
3. Open index.html using Live Server.
4. Navigate through Home, Destinations,
   About and Contact.
5. Test browser back and forward buttons.

### Conclusion
This project demonstrates the development
of a Single Page Application using HTML,
CSS and JavaScript. It provides dynamic
navigation without full-page reloads.
